DDG Lab bundled third-party notices

The notices in this directory accompany the corresponding runtime dependencies
and web fonts; see package-lock.json in the source distribution for versions.

The DDG CJK UI subset is derived from Google Fonts' NotoSansSC[wght].ttf,
Git blob fb0637bafbcd804fe32152370a1225990745b4bc, under the SIL Open Font
License in OFL-NotoSansSC-subset.txt. The complete fontsource Noto Sans SC
unicode subsets remain available as fallback for other characters; see
OFL-NotoSansSC-fallback.txt. The subset generation script is
scripts/subset-ui-font.py in the source distribution.
