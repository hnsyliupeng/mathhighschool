# 腱驱五指与不同物体的动态接触：降阶研究模型

> **范围：**本页首次让五根具有实体外表面和孔中腱线的手指直接接触自由运动、可变形的物体，且物体反力会反馈到各指的形变坐标。它**不是**独立球形指垫模型；也**不是**物体载荷下对五根手指所有 Q1 节点、腱节点和物体进行全自由度联立的求解器。用户要求的全自由度、不同物体和全部收敛验证尚未完成，不能将这里的数值试算称为完整验收。

入口：`?page=tendon3d`，侧栏“腱驱五指动态抓取”。可选择螺丝刀、鸡蛋、瓶盖和布片，改变尺寸、材料弹簧刚度、物体横向初始位置、腱目标、驱动刚度与摩擦；支持播放、暂停、视角、透明腱、网格、接触点、CSV、PNG 和 GIF。页面在 Worker 中求解，计算可能慢于实时。旧的 `?page=materials3d` 仍是**互不耦合的球形指垫实验**；固定物体下对每指全部 Q1 自由度求解位于 `?page=objects3d`。不要混用三个实验的结果。

## 1. 真实腱驱实体指参考轨迹

单指的参考帧由 `ContinuousGripper3D` 计算：标准网格 136 个 Q1 六面体（288 个实体节点），23 段有限半径腱，孔壁采用**整段—三角形**距离和五个特征约束，包含大变形超弹性、腱拉伸/弯曲和腱尾锚固。完整推导与安全边界见 [TENDON_GRIPPER_3D.md](TENDON_GRIPPER_3D.md)。指、腱的每个参考状态并非人工指定关节动画，数据来源为

```text
scripts/precompute-tendon-manifold.ts
src/data/tendon-grasp-manifold.json
docs/screenshots/tendon-manifold-audit.json
```

参考轨迹共 60 个接受状态，规范化拉程 0—14.75 mm，末段角 92.2914°。最大自由节点残差 `1.990e-5 N`，接受帧腱—孔壁最大压入 `1.864e-8 m`；对每对相邻参考帧的**直线插值**另外调用连续安全检测，最小路径 `J` 下界 `0.8437422`。该路径检测允许至多 2 μm 的临时腱压入，不能误称绝对零穿透；本检查也不是所有材料、网格及大变形工况的收敛证明。

第 `i` 指采用成人手尺度相似变换（拇指到小指的标称长度约 62.4、72、80、73.6、62.4 mm），记参考拉程为 `p_i`、缩放为 `s_i`、参考网格节点为 `x_j^k`，则

\[
  x_j(p_i)=(1-\theta)x_j^k+\theta x_j^{k+1},\qquad
  X_{ij}=B_i+s_iR_i\bigl(x_j(p_i)-[0,0,0.004]^T\bigr)+w(t)e_z.
\]

`theta=(p_i-p_k)/(p_{k+1}-p_k)`。腱节点同样插值并作同一变换，实际腱拉程是 `s_i p_i`。因此画面中的每根腱和指面均来自实体求解数据；物体接触时使用的也是这 520 个指面三角形，而非虚拟球指垫。

**重要局限：**受力时手指仅可沿这条自由指轨迹前后变化，不能产生偏离这条路径的三维局部压缩、扭转或侧弯；插值后的状态也不保证严格满足完整 Q1 平衡及腱接触互补条件。相邻轨迹的保守 CCD 检查不能把降阶模型变成全自由度接触求解。手掌/手腕仅为规定运动与支承显示，未求解掌面接触。

## 2. 动力学与双向虚功

自由参考轨迹中首腱段拉力 `T_0(p_i)` 作为近似回弹力，手指广义惯量采用假设值 `M_i=0.04 s_i^5 kg`，阻尼因子 `exp(-1.6 Δt)`；驱动器势能是

\[
 U_{\mathrm{drive},i}=\tfrac12 k_d s_i^2(p_i-u_i)^2,\qquad
 Q_{\mathrm{free},i}\approx-s_i^3 T_0(p_i).
\]

这不是经实验标定的质量矩阵、阻尼或电机模型。尤其 `T_0` 是**第一段轴向拉力的大小**，不是包含方向和弯曲项的精确驱动端反力；故本近似并非严格保守的完整 Q1 约化。`scripts/audit-tendon-manifold-energy.mjs` 对 58 个内部参考帧作中心能量差分，最大差 `0.00735 N`，最大相对差约 `1.82%`（相对分母下限 0.001 N）；这只是差分检查，不是证明两者相等。

物体以实际三角网格和距离弹簧表示，节点具有质量、速度与重力。螺丝刀是近刚性连杆网，鸡蛋为椭球弹簧壳，瓶盖为简化薄壳，衣物为拉伸/剪切/弯曲弹簧布；它们都不是标定过的真实材料，鸡蛋无破裂，瓶盖无螺纹。三维物体质量按尺寸 `s³`、布片按 `s²` 缩放；改变刚度会改变**求解弹簧**的 `k`。

对指面三角形和物体三角形求最近点 `x_f=Σa_jX_j`、`x_o=Σb_jq_j`，设 `n=(x_f-x_o)/||x_f-x_o||`，接触间隙（包含假设的 0.5 mm 接触皮肤）

\[
 C_n=\|x_f-x_o\|-h,\quad
 J_i=\partial x_f/\partial p_i,\quad
 \nabla_{p_i}C_n=J_i^Tn,\quad
 \nabla_{q_j}C_n=-b_jn.
\]

因此位置乘子变化 `Δλ` 对手指做功 `J_i^T(nΔλ)`，同时向物体三个节点分配 `-b_j nΔλ`。这是**反力确实改变腱的形变坐标**的双向耦合，但被固定根部/腕部及单形状坐标约束后的系统不是完整自由指动量守恒模型。腱坐标被限制在参考路径范围，边界限位反力没有单独求解。

法向采用单侧 XPBD，`α=(120000 Δt²)^{-1}`：

\[
 \lambda_n^{new}=\max\left(0,\lambda_n+\frac{-C_n-\alpha\lambda_n}
 {M_i^{-1}(J_i^Tn)^2+\sum_jm_j^{-1}b_j^2+\alpha}\right).
\]

切向使用同一物质点在本子步中的相对位移，投影满足 `||λ_t||≤μλ_n`。它是位置级、每步重置的近似摩擦：未实现持久静摩擦状态，切向质量采用保守标量近似，不能保证精确角动量或材料摩擦行为。三角对的重复约束及接触刚度可能随网格改变；`λ/Δt²` 显示为估计力，不是实验测力。只统计正乘子且间隙不大于 20 μm 的显示接触。

## 3. 过程和拒绝条件

- 闭合至 `0.78 s`；形状为实体物体时，初期在最多四个底部节点施加**固定临时夹具**，布片固定上沿节点。这些是外部反力，不是手指的抓取力；`0.95 s` 结束后完全解除。`1.08 s` 后手腕上升，默认抬升 50 mm。没有物体—桌面、夹具—手指或掌面碰撞模型。
- 每一请求步最多递归细分 4 层；失败则**物体位置、速度、五根腱坐标、速度、时间一起回滚**。预测迭代时临时交叉可用上一接受态法线修正；最终三角面交叉仍拒绝。
- 接受帧要求离散最大指—物体皮肤压入不超过 0.25 mm、法向互补残差不超过 0.25 mm、结构弹簧应变不超过 100%、三角面不退化。后两者及 0.25 mm 阈值只是数值保护，并非材料强度或精度保证。
- 默认逐步检查指—指与指—物体三角面的连续碰撞；参考指形跨插值区间时分段检查。物体节点和腕部在每个接受子步之间采用直线运动，指形在参考段内线性：判定只覆盖**该定义的分段线性路径**。任一碰撞或无法认证即拒绝；关闭 CCD 的试算不算安全通过。
- “短时保持”只在完整 2.15 s、夹具释放后、末 0.2 s 质心至少升高 25 mm，拇指与另一指持续有显示接触，物体相对腕部漂移不超过 10 mm，每个接受子步都执行 CCD，且数值保护全部满足时显示。它是**本降阶模型的有限时段指标**，并非三维摩擦力闭合或真实抓取认证。
- 底层 `summarizeTendonDynamic` 只适用于已经确保完整的逐请求步历史；页面和 Worker 使用 `summarizeCompleteTendonDynamic` 检查时间步数量、时间顺序、有限性、夹具释放、CCD 与数值保护，缺步及稀疏播放不能自行判定保持。预计算回放使用原完整报告摘要，额外测试会核对所有请求步、采样帧与报告中所列源码哈希。完整报告的逐步标量目前未保存互补残差；该残差在求解时逐子步检查，只有采样帧记录了它，因此不能从报告事后独立重算全程残差最大值。

## 4. 数值结果与未完成项

本节以仓库中的 `docs/screenshots/tendon-dynamic-*-ccd.json` 为准；每份报告包含参数、源码哈希、失败原因、逐步数据及是否逐步执行 CCD。以下是完整 2.15 s 试算，`Δt=1/240 s`、40 迭代、五指各一个坐标、夹具在 0.95 s 后释放，逐步执行指间及指—物体 CCD：

| 工况 | 不同尺寸和布置 | 结果（本降阶实验的末 0.2 s 指标） |
|---|---|---|
| 鸡蛋 | 尺寸 100%，横移 −13 mm，驱动 150 N/m，摩擦 1.5 | 达到短时保持：最小抬升 51.880 mm，持续 4 指接触含拇指，相对腕部漂移 0.052 mm；最大皮肤压入 0.0420 mm，最大结构弹簧应变 13.76%。 |
| 螺丝刀 | 尺寸 80%，横移 −13 mm，其余同上 | **未达到**：末段抬升约 55.13 mm，但仅 1 指接触且无拇指接触，不能把单指托起称为抓取。 |
| 螺丝刀（对指调整） | 尺寸 80%，横移 −22 mm，其余同上 | 达到短时保持：末段至少上升 46.651 mm，3 指接触含拇指，相对腕部漂移 0.158 mm；最大皮肤压入 0.00191 mm。该工况未完成时间步及网格收敛验证。 |
| 瓶盖 | 尺寸 130%，横移 −13 mm，其余同上 | **未达到**：夹具释放后脱落；模型没有桌面碰撞，物体继续自由下落。 |
| 瓶盖（对指调整） | 尺寸 130%，横移 −22 mm，驱动 200 N/m，腱目标 14.75 mm，摩擦 1.5 | 达到短时保持：末段至少上升 51.777 mm，4 指接触含拇指，相对腕部漂移 0.0144 mm；全程最大皮肤压入 0.0337 mm、结构弹簧应变 21.33%。末段互补残差约 0.236 mm，接近 0.25 mm 数值保护上限；没有时间步和网格收敛或材料强度验证。 |
| 鸡蛋（物体 4 倍刚度） | 尺寸 100%，横移 −13 mm，其余同基线 | 达到有限短时保持：末段至少上升 50.494 mm，4 指含拇指，相对腕部漂移 0.102 mm；全程最大皮肤压入 0.0914 mm、最大结构弹簧应变 5.98%。未完成时间步、网格或真实材料验证。 |
| 衣物布片 | 尺寸 100%，横移 0，驱动 150 N/m，摩擦 1.5 | **未达到**：末段虽有 5 指显示接触，但至少抬升仅 17.881 mm，低于 25 mm 判据；末时质心相对腕部下降约 32.08 mm。无布片自碰撞或桌面碰撞，不能称为成功抓取。 |

鸡蛋、对指调整后的螺丝刀和瓶盖录像各由 516 个实际请求步的轨迹抽取 12 帧，分别为 `src/data/tendon-egg-recording.json`、`src/data/tendon-screwdriver-recording.json`、`src/data/tendon-cap-recording.json`，与原报告的源码哈希绑定，可在界面选择“查看预计算轨迹”立即播放；**不是人为动画**，但 12 帧不能代表全过程最高残差。对应的 [鸡蛋 GIF](media/tendon-dynamic-egg.gif)、[螺丝刀 GIF](media/tendon-dynamic-screwdriver.gif) 和 [瓶盖 GIF](media/tendon-dynamic-cap.gif) 也只包含这 12 帧。鸡蛋完整逐步报告末段 48 帧中，无名指显示法向力约 `0.789—2.562 N`，存在明显振荡；12 个抽样帧中法向互补残差最高 `0.2326 mm`，接近 `0.25 mm` 数值保护上限。

**时间步对照未收敛：**在夹具仍开启的前 0.6 s，`1/240 s` 与 `1/480 s`、均为 40 迭代的 145 个共同时间点比较，中指接触力最大绝对差 `6.451 N`，为两轨迹该指峰值的 `97.5%`；`t=0.6 s` 两者分别约 `5.179 N` 与 `0.389 N`。手指拉程的最大差约 `0.110 mm`，物体质心升高最大差约 `0.056 mm`。见 `tendon-dynamic-egg-time-step.json`。这只是闭合阶段的对照，未覆盖夹具释放和抬升。几何接近并不意味反力收敛；因此即使这一有限时段保持指标满足，也**不能声称接触或时间步验证通过**。

**刚度变化对照：**同一鸡蛋工况把物体全部弹簧刚度提高到 4 倍，在 `t=0.6 s`（夹具尚未释放）时，最大结构弹簧应变由基线约 `3.07%` 降至 `0.698%`，中指显示法向力约由 `5.179 N` 变为 `4.882 N`。报告为 `tendon-dynamic-egg-stiffness4-ccd.json`；完整 2.15 s 报告为 `tendon-dynamic-egg-stiffness4-full-ccd.json`，有限保持指标见上表。这些数值不证明刚度变化下的收敛，且基线接触力已显著依赖时间步。

独立 Python 凸 QP 对鸡蛋的 12 个采样帧检查 5,898 个邻近三角对、202 个报告接触，最大未报告穿透差 `3.82e-17 m`，重建指/腱坐标误差约 `1.39e-17 m`，摩擦圆超限约 `3.47e-18 N`；螺丝刀对指工况检查 2,826 邻近对、164 个接触，瓶盖对指工况检查 6,645 邻近对、234 个接触。仅为采样静态重组，不能证明路径全局安全。不同尺寸、形状和刚度的结果必须分别核对，不能把一个对象成功推广至其他对象。

**仍未完成：**五指/腱/物体全自由度双向联立；五指加载后的准确 Q1 平衡与切向接触；所有对象/尺寸/刚度的抓取成功；物体及布片自碰撞、物体内部体积约束、夹具与掌面接触；空间网格及时间步收敛、形变/摩擦/驱动参数实验标定；真实力闭合与持久抓取测试。此前单指 Q1 网格腱力误差仍未达到 5% 收敛要求，不能因为当前界面有动画而声称全部验证通过。

## 5. 可复现检查

```bash
npx vite-node scripts/precompute-tendon-manifold.ts
node scripts/audit-tendon-manifold-energy.mjs
npx vite-node scripts/audit-tendon-triangle-cases.ts
OPENBLAS_NUM_THREADS=1 PYTHONPATH=/path/to/numpy python3 scripts/audit-tendon-triangle-independent.py
npx vite-node scripts/audit-tendon-dynamic.ts --id egg \
  --out docs/screenshots/tendon-dynamic-egg-ccd.json \
  --snapshots /tmp/tendon-dynamic-egg-snapshots.json
OPENBLAS_NUM_THREADS=1 PYTHONPATH=/path/to/numpy python3 \
  scripts/audit-tendon-dynamic-independent.py /tmp/tendon-dynamic-egg-snapshots.json
npm test && npm run build
```

独立 QP 测试只验证抽样的静态三角形最近距离及所记录状态；不能代替连续碰撞数学证明、收敛研究和物理实验。`audit-tendon-dynamic.ts` 在开始和结束比较报告列出的源码与数据哈希：这些文件中途变动时报告失效；它不覆盖全部传递依赖。
