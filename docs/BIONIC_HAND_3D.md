# 五腱驱三维仿生手：固定球体接触研究原型

> **总体严格验收未通过。** 当前球体被外部固定支撑，模型只包含无摩擦法向接触，不能自由平衡、提起或搬运物体，也没有力闭合验证；掌部和拇指安装座只是固定支撑的显示几何，未参与掌—指或掌—球接触求解。数值结果不是人体或工程性能预测。单指已知网格收敛不通过，五指加密收敛尚未完成。

## 入口与使用

运行 `npm ci && npm run dev`，访问 `/?page=hand3d` 或在侧栏选择「三维五指仿生手」。五个滑块的单位为各根腱的**实际物理牵引位移**；点击应用后从初态重新计算，并非真实卸载。可以暂停、回看已接受的平衡帧、旋转透视、显示网格和接触点、导出 CSV/PNG/GIF；播放速度不代表动力学时间。默认目标为中指相似坐标 6.75 mm、其余各指按尺寸缩放。求解较慢；求解、CCD 不确定或干涉时整次五指增量回滚，历史及导出不包含失败试探。

每个指体的标准网格包含 136 个全积分 Q1 六面体，其孔是网格中真实缺失的矩形孔腔；独立腱均由 23 个可滑动有限半径线段组成。掌部显示尺寸约 104 × 68 × 12 mm，拇指根部有显示安装座；球直径 90 mm。掌部和安装座不施加额外力，也没有碰撞约束；真正的边界是各指根部固定自由度与各腱的独立位移约束。球固定于空间，不能将屏幕上的球解释成自由物体。

## 2. 相似缩放与本构

令 $\hat x$ 为单指坐标沿截面宽度方向减去孔中心 4 mm 后得到的坐标（高度方向仍以指体底面为零），$R_i$ 为正交指体姿态，$b_i$ 为指根位置：

$$x_i=b_i+s_i R_i\hat x,\qquad E_i=s_i^3\hat E_i,\qquad f_i=s_i^2R_i\hat f_i.$$

因此实体杨氏模量仍为假设的 250 kPa、泊松比 0.35；物理腱轴向刚度 $EA_i=s_i^2\widehat{EA}$，弯曲刚度 $B_i=s_i^4\widehat B$，驱动、半径、位移均乘 $s_i$，力乘 $s_i^2$。单指的参考 $\widehat{EA}=30\,\mathrm N$、$\widehat B=2\times10^{-8}\,\mathrm{N m^2}$。如输出的力矩以指根为参考则乘 $s_i^3$。这是数学相似变换，不是对成人手生理参数的测定。

指体采用可压缩 Neo-Hookean 势能：

$$W(F)=\frac{\mu}{2}(\operatorname{tr}F^TF-3)-\mu\log J+\frac{\lambda}{2}(\log J)^2,\quad J=\det F.$$

每个指体和其腱都是独立未知量；各根腱与该指孔壁、孔口及所有其他离散边界之间使用有限半径**整段—三角形**接触。每对分解为两端点—面和三条段—边特征，重合项是冗余约束、乘子合起来形成接触反力。双向力、局部平衡、静态穿透和数值路径 CCD沿用单指研究模型，具体推导与已知失败项见 [单指文档](TENDON_GRIPPER_3D.md)。不同指体的腱—外指交叉接触未实施。

## 3. 球体—指体反力

对球心 $c$、半径 $R$ 和指体表面离散三角形 $T_j$，独立求最近距离及间隙 $g_j=d(c,T_j)-R$。在每个增广外迭代中：

$$\lambda_j^+=\max(0,\lambda_j-k_jg_j),\quad E_{c,j}=\frac{(\lambda_j^+)^2}{2k_j},\quad k_j=K_A A_j^0.$$

$A_j^0$ 为三角片参考面积；参考尺度数值系数 $K_A=2\times10^8\,\mathrm{N/m^3}$ 是算法参数，不是实验测得的接触刚度。相似变换后的物理系数等效为 $K_A/s_i$。如果 $p_j$ 是三角形最近点、$n_j=(p_j-c)/\|p_j-c\|$，则球对指体的法向力是 $\lambda_j^+ n_j$，通过最近点重心坐标分配到三个实体节点；指对球的反力是其相反数。球体由外部支座提供与**五指对球合力**相反的力，故不存在自由球的力、力矩平衡方程。无摩擦、无重力和粘附，接触切线采用正的 Gauss–Newton 近似。

每个指体的自由自由度求解

$$\nabla_{q_{i,\mathrm{free}}}(E_{\rm solid}+E_{\rm tendon}+E_{\rm wall}+E_{\rm sphere})=0.$$

每次成功步检查自由残差、根部力及力矩平衡、腱孔和球体互补性与穿透、表面自交、分解四面体静态重叠和 $J$。球面与三角面的线性迭代路径采用保守连续碰撞检测，最多允许相似坐标 2 μm 的临时压入，最终收敛穿透及互补残差各不超过相似坐标 0.02 μm。五指已接受帧之间还对**不同指体的离散三角面**做线性插值 CCD；失败或不确定先同步缩步，仍失败则坐标、腱孔乘子和球体乘子全部回滚。该检查不为手指间接触产生反力，不检查指间连续体内部或曲面 CCD，也不覆盖所有可能的物理加载轨迹。

## 4. 数值审查及限制

- 当前源码的 8 mm 路径**未完成**：相似牵引到 7.00 mm 的请求中，拇指—食指表面 CCD 在距离约零时返回 **indeterminate**，同步自适应缩步仍未能认证，于是五指全部回滚至 6.75 mm。不能把“不确定”说成已确定相交，也不能放行它。该 6.75 mm 构型五指均有腱孔与球接触，球对指的拇指力仅约 `4.9e-5 N`，其余四指约 `0.00385–0.03096 N`；指对球合力约 `0.05938 N`，五指最大腱孔穿透约 `0.00860 μm`、球体穿透约 `0.00179 μm`。五指末段角分别为 `42.77° / 40.85° / 35.15° / 34.62° / 41.52°`，明显小于单指自由卷曲 92.29°，且球体与邻指约束会改变形状。
- [路径记录](screenshots/bionic-hand-audit.json) 的每项条件、失败原因和源码哈希为准；`strictGraspAcceptance` 始终为 `false`。**不要把局部路径数值收敛或五指均有非零球接触，解释成自由抓取验证。**
- 对相似牵引 6.75 mm 的五个指定构型，独立 NumPy/SciPy 重组全部指体 Q1 能量、腱及孔壁特征，并枚举球—三角面候选进行独立约束最优化：五指腱孔活动项为 `16 / 22 / 22 / 22 / 22`，球体活动面为 `6 / 6 / 2 / 2 / 4`；最大能量差 `6.40e-18 J`，梯度分量差 `1.30e-14 N`，球面距离差 `1.38e-13 m`，候选未漏报非零接触力。[6.75 mm 独立记录](screenshots/bionic-hand-independent-audit.json) · [3.5 mm 独立记录](screenshots/bionic-hand-independent-3p5mm.json)。这些只验证指定构型，不验证完整路径或实验。
- 单指制造解已暴露 Q1 剪切锁定；3 mm 标准到二级网格的腱力差约 20.31%，14.75 mm 的 23→46 腱段力差约 6.70%。五指模型继承这些限制；当前五指没有网格、腱段、加载步长收敛结果。
- 接触面是三角片，实体 Q1 面可能是双线性曲面；静态四面体分解和路径全域 $J$ 下界不能替代完整的连续体内部/曲面 CCD。Bernstein 检查带浮点保守裕量，不是形式化证明或全局单射证明。
- 指间碰撞仅做拒绝，不计算指间接触力；掌部、手指—外指腱接触、球的运动/摩擦/重力、真实驱动器、动力学、断裂、黏弹性、实验标定及力闭合均未完成。严格验收必须逐项补齐，不能仅以可视合拢或残差小判定通过。

## 5. 复现

```bash
npm ci
npm run dev                              # /?page=hand3d
npx vitest run src/engine/__tests__/bionic-hand3d.test.ts
npx vite-node scripts/audit-bionic-hand.ts # 8 mm 路径；未达到或任一条件失败时非零退出
npx vite-node scripts/snapshot-bionic-hand.ts 27  # 6.75 mm 的五个快照，写 /tmp
python3 scripts/audit-bionic-hand-independent.py  # 需要 numpy、scipy
# 浏览器审查需要 playwright-core 与 Chromium；按脚本开头的环境变量配置
node scripts/audit-bionic-hand-browser.mjs
```

五指研究性求解实现为 `sphere-finger3d.ts`、`hand-object-contact.ts` 和 `bionic-hand3d.ts`，通过 Worker 与 `BionicHandLab.tsx`/`BionicHandViewport.tsx` 连接。为不改变已审查单指求解器的源码哈希，球体扩展暂为隔离的求解器副本；后续需在两者共用的经过验证的核心上重构。该五指求解使用 TypeScript，**不调用 Rust/WASM**。
