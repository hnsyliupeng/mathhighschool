# 腱驱软体抓手：模型、推导和验证边界

这是根据用户示意图新增的**自定义实验**，不是 DDG_Tutorial 原 21 个算例之一。图中没有尺寸、材料试验曲线或实际孔道 CAD，因此以下尺寸和材料参数只是可调整的示例。入口是侧栏「腱驱软体抓手」或 `/?page=gripper`。

## 1. 范围与重要限制

- 本模型是**二维平面应变、准静态**：柔性指体采用三角形有限元和可压缩 Neo-Hookean 材料；腱是只受拉的可伸长折线，末端锚固于指体，根部通过位移驱动。
- 四处导向孔采用**与指体耦合的移动截面等效**：截面的位置、朝向和有效半间隙跟随柔性材料变形。超出间隙时形成单边罚接触，接触能的梯度和一致切线参与整体平衡；这不是纯动画或只改变显示颜色。其余位置不进行连续碰撞检测。
- **指体有限元网格没有挖出真实孔洞。** 截面只是嵌入在实心指体中的降阶孔壁表示；它不解析三维可变形孔面、腱的有限半径、连续接触、孔口边缘或接触面压强。画面的圆环/箭头是放大标记，不是可量测的实体孔几何。
- 按整条腱的总伸长计算统一张力，从而允许腱材料通过导向截面滑动；不含库仑摩擦、粘结或摩擦滞回。腱折线站点被约束在各虚拟截面上，这个离散化还可能产生**截面轴向约束反力**，界面单独报告，不能把它当成真实摩擦。应在实际工况检查它相对于腱张力是否足够小。
- 不包括惯性、粘弹性、腱自接触、指体自接触、多个手指、物体/抓取接触、撕裂或材料损伤。可选加载后卸载是逐步重求解的弹性平衡路径，不是有时间尺度的动力学。未与实测或商业有限元进行整机验证，**不能直接用于设计或预测夹持力**。
- 当前网格敏感性明显，见第 5 节；小残差只表示离散方程达到平衡，不能证明连续解已收敛。

## 2. 几何、材料与边界

以指体纵向为 $x$，横向为 $y$，计算使用 SI 单位：

| 项目 | 默认示例 |
|---|---|
| 指体 | 长 80 mm、高 14 mm；连续背梁高 7 mm；五个 12 mm 宽牙片，每片后有 4 mm 缺口；平面应变面外厚度 8 mm |
| 网格 | 标准 103 节点 / 140 个线性三角形；可选择加密 345 节点 / 560 个三角形 |
| 边界 | $x=0$ 端整条边固定；最远自由端中心节点 $(80,3.5)$ mm 的横向位移为指端指标 |
| 孔截面 | 参考状态在 $x=4,20,36,52$ mm，$y=10.5$ mm；腱锚定点在 $(68,10.5)$ mm；初始半间隙 $c_0=0.4$ mm |
| 指体 | $E=250$ kPa、$\nu=0.35$，均为示例而非实测拟合 |
| 腱 | $EA=30$ N、微小弯曲刚度 $B=2\times10^{-9}$ N·m²；参考总长 80 mm |
| 接触与驱动 | 罚刚度 $k_n=5000$ N/m；驱动端从 $(-12,10.5)$ mm 朝负 $x$ 牵引至 4 mm；每步最多 0.2 mm |

标准和加密网格使用相同的名义外轮廓。固定边附近应力受网格和约束离散影响，单元最大应力不应当作已收敛的强度结果。

## 3. 详细方程

### 3.1 指体：平面应变超弹性

每个线性三角形的形变梯度由参考形函数 $N_a$ 组装：

$$
F_{iJ}=\sum_a x_{ai}\,\partial_J N_a,\qquad J=\det F>0.
$$

在三维可压缩 Neo-Hookean 模型中取 $F_{zz}=1$，面内 $F$ 为 $2\times2$，参考体积为三角形面积乘面外厚度：

$$
W(F)=\frac{\mu}{2}(\operatorname{tr}F^TF-2)-\mu\ln J
     +\frac{\lambda}{2}(\ln J)^2,\quad
\mu=\frac{E}{2(1+\nu)},\quad
\lambda=\frac{E\nu}{(1+\nu)(1-2\nu)}.
$$

$$
P=\frac{\partial W}{\partial F}=\mu F+(\lambda\ln J-\mu)F^{-T},\qquad
\frac{\partial E_s}{\partial x_{ai}}=V_0P_{iJ}\partial_J N_a.
$$

程序组装一致切线 $\partial P/\partial F$，并在试探构型 $J\le0$ 时拒绝该步。显示的是由 Cauchy 应力计算的三维 von Mises 等效应力，包含平面应变下 $\sigma_{zz}$，不是孔壁接触压强。

### 3.2 可滑动的只受拉腱

将驱动端、四个虚拟截面站点和末端锚点记为 $p_0,\ldots,p_5$：

$$
L=\sum_i\lVert p_{i+1}-p_i\rVert,\quad
E_t=\frac{EA}{2L_0}\langle L-L_0\rangle_+^2+E_{\rm bend},\quad
T=\frac{EA}{L_0}\langle L-L_0\rangle_+.
$$

这里 $\langle z\rangle_+=\max(z,0)$。使用总长度而不是给每段单独固定原长，使腱材料可以穿过孔截面滑动，且拉伸部分的张力统一。为避免松弛腱横向退化，加入明确计入能量的微小弯曲项：

$$
E_{\rm bend}=\sum_{i=1}^{4}\frac{B}{2\bar\ell_i^3}
\lVert p_{i-1}-2p_i+p_{i+1}\rVert^2.
$$

它是模型的一部分而不是隐藏的数值阻尼，也意味着站点切向反力不必严格为零；界面展示该反力。

### 3.3 变形导向截面与单边接触

对于每个导向截面，两个材料节点 $a,b$ 定义单位切向和法向，$R$ 表示逆时针旋转 90°：

$$
t=\frac{x_b-x_a}{\lVert x_b-x_a\rVert},\quad n=Rt,\quad
p_j=\tfrac12(x_a+x_b)+s_jn.
$$

$s_j$ 是腱与截面的有向横向偏移；$p_j$ 是**虚拟穿越站点**而非固定腱材料点。两个横向材料节点 $x_l,x_u$ 的当前投影长度决定有效半间隙：

$$
c_j(x)=c_0\frac{(x_u-x_l)\cdot n}{h_0},\qquad
\delta_j=\langle|s_j|-c_j(x)\rangle_+.
$$

若 $c_j\le0$ 或单元翻转，试探构型被拒绝。法向接触势与作用于腱的法向力为：

$$
E_c=\sum_j\frac12k_n\delta_j^2,\qquad
f_{j,\rm tendon}=-k_n\delta_j\operatorname{sign}(s_j)n.
$$

$\delta_j=0$ 时罚接触力为零；活动时 $\delta_j>0$，数值允许有限穿透，不是精确不可穿透。指体与腱同时出现在总能量中：对 $x_a,x_b,x_l,x_u,s_j$ 求导，包含导向截面旋转和间隙伸缩的链式项；耦合切线的这一部分也经有限差分检查。虚拟截面站点的轴向几何约束会产生额外约束反力，因此不应把该降阶模型误称为完整、严格无摩擦的三维孔接触。

### 3.4 准静态路径

固定底部和驱动位移，最小化总势能：

$$
\nabla_{q_{\rm free}}(E_s+E_t+E_c)=0.
$$

每个牵引增量采用带线搜索的 Newton 法；对不正定切线尝试对角稳定，检查自由度残差范数小于 $2\times10^{-7}$ N。失败或翻转的试探态回滚，**不会**作为成功样本加入曲线或 CSV。支持播放、暂停、单步、历史回看、弹性卸载和导出收敛样本；时间轴是加载位移，不是动力学时间。计算在 TypeScript Web Worker 中进行，Worker 不可用时主线程回退；并未调用 Rust/WASM 求解器。

## 4. 如何复现与审查

```bash
npm ci
npm run dev
npx vitest run src/engine/__tests__/gripper.test.ts
npx vite-node scripts/audit-gripper.ts --snapshot /tmp/gripper-snapshot.json
# 可选的独立 NumPy / SciPy 重组与局部松弛；需先在环境安装 numpy 和 scipy
python3 scripts/audit-gripper-independent.py /tmp/gripper-snapshot.json
# 可选浏览器审查：需单独安装 playwright-core 与 Chromium
AUDIT_MODULE_ROOT=/path/to/browser-dependencies CHROME_BIN=/path/to/chromium \
  node scripts/audit-gripper.mjs
```

界面默认自动加载。可更改材料模量、驱动位移、初始孔隙、罚刚度、腱轴向刚度和网格，再点「应用并重新计算」；勾选「到达最大牵引后卸载」可实际计算回程。导出 CSV 包含每个收敛态的四个孔法向力、穿透量、变形后半间隙和截面轴向反力。主图可切换网格、初始轮廓及孔壁力箭头。

## 5. 本轮数值结果与局限

默认 4 mm 加载、标准网格的结果（不是物理实测）：

| 指标 | 结果 |
|---|---:|
| 末端横向位移 | 17.712 mm |
| 腱张力 | 0.18285 N |
| 接触中的导向截面 | 4 / 4 |
| 最大孔法向力 | 0.01935 N |
| 最大罚穿透 | 3.870 μm，约为该处变形半间隙的 0.96% |
| 最小单元 $J$ | 0.96278 |
| 最大单元 von Mises 应力 | 10.52 kPa |
| 末态固定端与驱动端反力合力 | $7.95\times10^{-13}$ N |
| 最大截面轴向约束反力 | 0.000477 N，约为张力的 0.26% |

- 将孔隙扩大到 10 mm 以消除这四处接触后，默认终态张力变为约 0.11853 N；接触状态确实改变耦合解，不只是可视标记。大间隙仅作为数值隔离试验，不在界面滑块范围内。
- $k_n$ 从 2500 增至 10000 N/m 时，最大穿透由 7.72 降至 1.94 μm，末端位移为 17.710→17.713 mm。极端参数（500 kPa、8 mm、初始半间隙 0.2 mm、$EA=60$ N、$k_n=2000$ N/m）的穿透约为当前半间隙的 37.6%；界面对此警告，不能把该构型当作高精度接触。
- 140→560 单元时，末端位移 17.712→19.126 mm（约 **+7.98%**），张力 0.18285→0.12592 N（约 **−31.13%**）；这不是网格收敛。若需定量预测，须进一步加密、改善孔壁建模并与独立数据比较。
- 默认加载再卸载至 0 后，末端残余约 $-8.1\times10^{-8}$ mm、张力约 $5.76\times10^{-9}$ N，接触数为零；这是无摩擦超弹性模型的数值可逆性检查，不能证明真实器件无滞回。
- NumPy 独立重组同一最终构型的能量和解析梯度，梯度最大差 $5.55\times10^{-17}$ N；六个方向的能量差分误差最大 $4.16\times10^{-10}$ N。SciPy L-BFGS-B 从**扰动后的 TypeScript 结果**局部松弛，节点坐标最大差 $2.12\times10^{-9}$ m、自由残差 $3.73\times10^{-7}$ N。它是局部交叉检查，不是独立加载全程或实验验证。
