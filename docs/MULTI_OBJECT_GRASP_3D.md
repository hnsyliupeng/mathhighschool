# 五指与不同物体：固定支撑接触研究原型

**结论先行：总体抓取验收未通过。** 本页计算的是不同形状的**固定、外部支撑、无摩擦刚体**对五个腱驱柔性指体的接触反力；物体不自由平动或转动，不含重力、摩擦和惯性。指对物体的非零合力和力矩由理想外部支座抵消，不能据此声称自由抓取、力闭合、抗滑、稳定搬运或已完成实验验证。掌部只用于显示固定指根，不参与掌—物接触；指间碰撞只拒绝数值路径，不提供接触反力。原单指的网格收敛已经有未通过项，其他缺项见末节。

## 入口与交互

`npm install && npm run dev` 后访问 `/?page=objects3d`，或在侧边栏选择「多物体接触验证」。选择形状和 65%–125% 的尺寸倍率、设置五指独立目标，点击「应用并重新计算」。指端角度是实体的实际末段转角；可播放、暂停、回看、旋转、透视观察腱与接触，导出 CSV、PNG 或逐收敛帧 GIF。显示的步数不是物理时间。移动设备同样可用，但五个非线性求解串行执行，完整路径可能较慢。

每次改变物体或目标都从初态开始计算，不是实际的卸载路径。每指默认相似步长 0.25 mm，驱动和物体几何均在 Worker 中参与求解；不确定或失败会缩步，最终仍失败则**整手的位移、腱孔乘子和物体接触乘子一起回滚**，失败帧不进入历史或导出。初始物体与指体相交也会拒绝，而不会自动调整位置。用户任意选择的尺寸和牵引不等于下表已验证工况。

## 假设尺寸与几何

五指长度为拇/食/中/无名/小指 `62.4 / 72 / 80 / 73.6 / 62.4 mm`，相似尺度为 `0.78 / 0.90 / 1 / 0.92 / 0.78`；中指参考横截面 `14 × 8 mm`，其他指按相同尺度缩放。这些仅为假设成人手的研究尺寸，不是人体测量或标定。指体使用带真实内部矩形孔的 Q1 六面体、可滑动有限半径腱及五特征腱—孔壁接触；参数、离散和此前的网格收敛问题详见 [单指文档](TENDON_GRIPPER_3D.md) 与 [五指文档](BIONIC_HAND_3D.md)。

## 接触推导

以凸核心 $C_p$ 和球 $B_{r_p}$ 定义第 $p$ 个物体部件，整个物体为

$$\mathcal O=\bigcup_p\left(C_p\oplus B_{r_p}\right),\qquad g_p(T)=d(C_p,T)-r_p.$$

其中 $T=(x_0,x_1,x_2)$ 是指体一片表面三角形，$d$ 是**整个闭合核心与整个闭合三角形**的最短距离，而不是顶点采样。球的核心为点、胶囊为线段、圆角盒为矩形。矩形核心可由两片闭合三角形组成，枚举两组边—面最短距离并检查穿越；对哑铃每片指体表面都分别对两个球设约束。对全部部件要求 $g_p(T)\ge0$ 等价于不与该几何并集相交；重叠部件附近的活动约束可能冗余，不能把活动约束数当成独立接触面积。

参考面积 $A_T$、假设接触刚度密度 $K_A=2\times10^8\ \mathrm{N/m^3}$ 给出 $k_T=K_A A_T$。增广接触为

$$\lambda^+ = \max(0,\lambda-k_T g),\qquad E_c=\frac{(\lambda^+)^2}{2k_T}.$$

取接触最近点 $x_T=\sum_j w_jx_j$、核心最近点 $x_C$ 及单位法向 $n=(x_T-x_C)/d$。在正规、可微的最近特征上，$\partial g/\partial x_j=w_j n$，故指体所受接触力为 $f_j=\lambda^+w_j n$；求解器将相反的能量梯度及正的 Gauss–Newton 接触切线装配进实体和腱的平衡。最近特征切换处不保证光滑；核心穿过三角面导致法向无法定义时直接拒绝，不静默接受。

局部指坐标与世界坐标用 $x_i=b_i+s_iR_i\hat x_i$ 变换，半径除以 $s_i$；物理接触力是 $s_i^2R_i\hat f$。指对物体合力及关于参考点 $x_0$ 的力矩为

$$F_{\mathrm{hand}\to\mathcal O}=-\sum_{i,c}f_{ic},\qquad M_{\mathrm{hand}\to\mathcal O}=\sum_{i,c}(x_{ic}-x_0)\times(-f_{ic}).$$

不计重力时，固定支座提供与该合力/力矩相反的支撑；这些量本身**不是自由物体平衡误差或力闭合结果**。

## 数值保护及审查范围

- 对每指、每个部件、每个表面三角形在 Newton 线性路径上做保守 CCD；球/胶囊用线段—三角形，圆角盒用两片矩形核心三角形与指体三角形。包围盒下界只跳过可证明分离的候选；`collision` 或 `indeterminate` 均不放行。
- CCD 仅覆盖离散表面及线性数值插值，允许最多 `2 μm` 的临时压入（局部相似尺度）；收敛构型接触互补及穿透门槛为局部 `2×10⁻⁸ m`。此外检查腱—孔壁、单指自交与体积、路径 Jacobian 浮点下界、指间已接受帧表面 CCD；这些不是曲面、连续体内部或全部物理路径的完整证明。
- 全量 Vitest 回归 `19` 个文件、`186/186` 通过，其中多物体新增 `9/9`；该测试通过不等于各物体加载路径或总体抓取验收通过。
- 随机几何交叉验证：360 个核心—三角形距离，以独立 NumPy 凸二次规划**活跃集枚举**重算，最大差 `7.72×10⁻¹⁶ m`；另对 256 组线段—线段距离重算，最大差 `5.55×10⁻¹⁷ m`。64 条数值轨迹每条独立采样 21 点，32 条判安全、32 条因不确定拒绝，抽样未发现放行轨迹穿入；仅用于发现漏检，**不能用离散抽样证明连续安全**。[独立几何记录](screenshots/rounded-object-geometry-independent.json)。接触力梯度还通过有限差分检查，退化输入、包含与回滚有单元测试。
- 五指每个指定路径逐步记录残差、支撑平衡、互补性、穿透、接触手指数、力、指间 CCD 与路径 $J$ 下界。结果只适用于指定物体、标准网格、参数、加载路径和浮点环境；接触手指数只要求非零活动力，即使极小也计数。
- **圆角盒仍有实质性非收敛问题。** 100% 尺寸下目标 2.25 mm 请求在前一接受点 2.00 mm 回滚。中指单独重放显示物体 CCD 试探出现 `indeterminate`，将 Newton 内迭代由 60 提高至 200 次后仍出现线搜索失败，残差约 `5.82×10⁻⁴ N`，高于 `2×10⁻⁵ N` 门槛；不得以增加迭代或放宽精度宣称修复。另试按矩形核心两三角形的 12 组边—面特征分别设冗余接触乘子，独立单指路径在 2.00 mm 后仍失败，最后尝试残差约 `5.96×10⁻⁵ N`；该研究实现未并入网页。诊断涉及特征切换，但尚未证明唯一根因。
