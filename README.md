# 高中立体几何 3D 互动解读 · 人教A版必修二第八章

一本可交互的「弹出式 3D 教材」：手绘墨线等距视角、360° 拖拽旋转、透视开关看内部与截面、
标注开关、五套配色（番茄红 / 芥末黄 / 薄荷绿 / 钴蓝 / 腮红粉），单个 `index.html` 离线可运行，零外部依赖。

## 打开方式

直接双击 `index.html`，或本地起一个静态服务器：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/index.html
```

## 工程

- `src/engine.js` — 自研 Canvas 2D 三维引擎（透视投影、画家算法、手绘抖动、球与大圆、拾取）
- `src/geo.js` — 几何体与标注库（棱柱/棱锥/棱台、旋转体、长方体、平面、直角标记、自动字母摆放）
- `src/app.js` — 书籍控制器（翻页、全局控件、分步例题、习题交互）
- `src/pages/*.js` — 12 页内容，注释中标注对应教材知识点编号
- `src/style.css` — 纸感书页视觉系统
- `build/build.mjs` — 打包为单文件 `index.html`（内联 CSS/JS，无外链）
- `test/render.mjs` — 无头 canvas 渲染回归（每页 + 各模式导出 PNG 到 `test/out/`）
- `test/app.mjs` — jsdom 交互冒烟测试（翻页、页签、答案展开、选项、滑块、配色、目录跳转）

```bash
node build/build.mjs      # 重新打包
node test/render.mjs      # 渲染回归
node test/app.mjs         # 交互回归
```
