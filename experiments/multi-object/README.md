# Rectangular-core multi-feature trial (not production)

`multifeature-finger.ts` is an isolated copy of the object finger solver used to test twelve redundant edge/face distances for each rectangular-core/triangle pair, rather than a single nearest feature. Each feature uses one twelfth of the face stiffness and an independent multiplier. It is **not** used by the web application. This changes the discrete contact formulation and has not been independently reassembled or mesh-converged.

Generate `/tmp/multi-object-rounded-box-snapshot.json` with `npx vite-node scripts/audit-multi-object.ts --id rounded-box --target 6.75`, then run `npx vite-node scripts/experiment-multi-object-box-features.ts`. The script takes only the middle-finger input from the snapshot and starts that finger at rest. In the recorded trial, it accepted 2.00 mm but the requested 2.25 mm increment and adaptive subdivisions failed; the last residual was about `5.96e-5 N`, above the `2e-5 N` acceptance threshold. Increasing the unmodified solver's inner Newton iteration limit from 60 to 200 also did not resolve the failing state. Neither experiment justifies weakening CCD, residual or penetration gates, and neither is promoted to the GUI.
